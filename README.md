# Embedded Development

This repository exists for education purposes. I use it to learn embedded development and to keep my practice projects in one place.

## Contents

The repository will hold small projects and experiments, such as:

- Microcontroller firmware (GPIO, timers, interrupts, peripherals)
- Communication protocols (UART, SPI, I2C)
- Build systems and toolchains for embedded targets
- Notes from books, courses, and datasheets

## Status

This is a personal learning repository. The code here is not intended for production use.
